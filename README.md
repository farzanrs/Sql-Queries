# SQL Server Advanced Queries & Practice

A comprehensive collection of SQL scripts, ranging from fundamental queries to advanced database concepts like concurrency control and procedural logic.

## 🚀 Project Overview
This repository serves as a portfolio of my SQL learning journey, covering T-SQL syntax, data analysis techniques, and database management best practices.

## 📂 File Structure & Descriptions

1. `setup-TSQLV4.sql`
   - Purpose: Full Database Deployment.
   - Content: Complete schema creation and full dataset population. This file provides a standalone environment, ensuring that all subsequent scripts can be executed immediately without needing external data sources.

2. `TSQLV4_Practice_Queries.sql`
   - Purpose: Core SQL Fundamentals.
   - Content: Basic SELECT statements, filtering, and data retrieval techniques.

3. `TSQLV4_Practice_Queries2.sql`
   - Purpose: Analytical Queries.
   - Content: Advanced JOINS, Aggregations, and Window Functions (like `DENSE_RANK`).

4. `TSQLV4_Practice_Queries3.sql`
   - Purpose: Procedural SQL.
   - Content: Stored Procedures and Cursors for row-by-row data processing and automated reporting.

5. `TSQLV4_Practice_Queries4.sql`
   - Purpose: Concurrency & Transaction Management.
   - Content: Implementation of Transaction Isolation Levels (Serializable, Snapshot) and Locking Mechanisms (XLOCK) to handle simultaneous data access.

## 🛠️ Skills Demonstrated
- Advanced T-SQL: Window Functions, Cursors, Stored Procedures.
- Database Performance: Transaction Management, Blocking & Locking.
- Logical Design: Schema separation and relational data modeling.

## 📖 How to Use
1. Run `setup-TSQLV4.sql` first to create the necessary environment and load the data.
2. Execute individual query files to see specific functionalities.
3. For Concurrency Tests, execute `sp_LockCustomers` and `sp_GetLastCommittedOrders` in separate query sessions.
